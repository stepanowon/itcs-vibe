# 국제 우주 정거장 추적 앱 개발

다음 조건을 반영해 국제 우주 정거장 위치를 지도위에 나타나는 실시간 앱을 작성한다.

1. 기능 요구 사항
- 실시간 국제 우주 정거장 정보는 다음 공개 API를 이용해 다운로드한다.
  * http://api.open-notify.org/iss-now.json 
- 우주 정거장의 위치가 지도상에 궤적으로 표시되어야 한다
  * 앱이 실행되는 동안의 좌표정보는 브라우저내의 IndexedDB에 저장해서 우주 정거장 위치 궤적을 표시하는데 사용한다.
  * IndexedDB에 저장하는 좌표 정보는 최근 4시간 이내의 정보만 유지하도록 한다.
  * 다음의 경우에는 좌표 궤적을 계산/유추하여 지도위에 최근 4시간의 위치가 표시되도록 한다. 
    * 저장된 좌표 궤적 정보에서 단절된 시간 구간이 있는 경우
    * 수집된 위치정보가 4시간 이내의 것이 없다면 데이터 수집 시점의 위치로 부터 4시간 전까지의 위치를 유추한다.
    * 4시간이 지난 위치 정보는 자동으로 삭제한다.
  * 계산/유추된 궤적은 점선으로 표현한다.
- 궤적을 표시하는 지도 아래에 우주 정거장의 이동 속도를 표시한다.
- API의 요청/응답 속도에 따라 Polling 간격을 능동적으로 조절하도록 한다.
  * Polling 시간 간격은 5초 이상을 유지한다.
  * API 응답속도를 매번 측정해서 실행 중에 API Polling 간격이 조정되도록 한다. 
  * API Polling 간격과 API 응답속도를 우주 정거장의 궤적을 나타내는 지도 아래에 표시하도록 한다. 
- 우주 정거장 위치에는 우주 정거장 모양의 아이콘을 만들어 표시한다.

2. 기술스택
- React 19 + Tanstack Query + Tanstack Query Devtools
- 프론트엔드 만으로 앱 개발한다.

3. 스타일
- @prompt/course.html 의 화면 스타일을 적용한다.
