---

사용자가 지정한 BE Task를 처리한다.

1. `docs/5-plan.md`에서 해당 Task와 선행 Task, 완료 조건을 읽고, 필요한 경우에만 `docs/1-prd.md`, `docs/2-user-scenario.md`, `docs/4-erd.md`, `backend/swagger.yaml`을 확인한다.
2. `backend`의 관련 코드와 기존 테스트·실행 명령을 먼저 확인한다. Task 범위 밖의 구조 변경이나 의존성 추가는 하지 않는다.
3. 완료 조건을 충족하는 최소 구현을 하고, 신뢰 경계·데이터 정합성·오류 응답은 명세를 따른다.
4. 앱 실행 시 로그가 남도록 기존 로거를 재사용한다. 없으면 기본 로깅으로 시작과 오류를 기록하며, 요청 본문·토큰·비밀번호·연결 문자열 등 민감정보는 기록하지 않는다.
5. 변경한 동작을 검증할 가장 작은 기존 또는 새 테스트를 실행하고, 실행 로그가 남는지도 확인한다. 완료 조건이 충족되지 않거나 테스트가 실패하면 테스트 출력과 관련 애플리케이션 로그를 확인해 원인을 고친 뒤 다시 검증한다.
6. 완료 조건이 충족될 때까지 3~5단계를 반복한다. 외부 서비스·환경 문제나 추가 권한 때문에 진행할 수 없으면 반복을 멈추고, 실행한 명령·관련 로그·원인·필요한 조치를 보고한다. 민감정보는 로그에 남기거나 보고하지 않는다.
7. 모든 완료 조건을 확인한 경우에만 `docs/5-plan.md`의 해당 체크박스를 갱신한다.
