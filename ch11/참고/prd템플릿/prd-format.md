# PRD 작성 형식은 다음과 같습니다.

```
1. 개요
  1.1 배경
  1.2 목표 : 이 프로젝트가 달성하고자 하는 목표
  1.3 비목표 : 이번 범위에서 명시적으로 제외하는 것
2. 문제 정의
  2.1 사용자 문제
3. 목표 및 성공 지표
  3.1 핵심목표
  3.2 성공 지표
  3.3 실패 조건
4. 사용자 시나리오
  4.1 페르소나
  4.2 사용자 스토리
5. 요구사항
  5.1 기능 요구사항
  5.2 비기능 요구사항(기술스택 포함)
  5.3 우선 순위 기준
6. 사용자 흐름
7. 범위
  7.1 In Scope
  7.2 Out of Scope
8. 엣지 케이스, 예외 처리할 것
9. 작업 일정
```
