---

사용자가 지정한 FE Task를 처리한다.

1. `docs/5-plan.md`에서 해당 Task와 선행 Task, 완료 조건을 읽고, 필요한 경우에만 `docs/1-prd.md`, `docs/2-user-scenario.md`, `docs/3-wireframe.md`, `backend/swagger.yaml`을 확인한다.
2. `frontend`가 있으면 관련 코드, 기존 컴포넌트·스타일·테스트·실행 명령을 먼저 확인한다. 없다면 해당 Task가 초기 설정을 요구할 때만 만든다.
3. 기존 스타일 가이드나 UI 패턴이 있으면 따른다. 없다면 와이어프레임과 기본 접근성을 충족하는 단순한 UI를 만든다.
4. 앱 실행 시 로그가 남도록 기존 로거를 재사용한다. 없으면 브라우저 기본 로깅으로 시작과 오류를 기록하며, 토큰·비밀번호·개인정보 등 민감정보는 기록하지 않는다.
5. 완료 조건을 충족하는 최소 구현을 하고, 변경한 동작을 검증할 가장 작은 기존 또는 새 테스트를 실행한다. 완료 조건이 충족되지 않거나 테스트가 실패하면 테스트 출력과 브라우저·애플리케이션의 관련 로그를 확인해 원인을 고친 뒤 다시 검증한다.
6. 완료 조건이 충족될 때까지 3~5단계를 반복한다. 브라우저·백엔드 등 외부 의존성이나 추가 권한 때문에 진행할 수 없으면 반복을 멈추고, 실행한 명령·관련 로그·원인·필요한 조치를 보고한다. 민감정보는 로그에 남기거나 보고하지 않는다.
7. 모든 완료 조건을 확인한 경우에만 `docs/5-plan.md`의 해당 체크박스를 갱신한다.
