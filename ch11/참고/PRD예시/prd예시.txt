# 소규모 사업장 근태관리 앱

## 대상
- 임직원 20명 내외의 소규모 중소기업

## 기능 요구사항
- 사용자는 회원 가입 후 로그인해야만 기능을 이용할 수 있다.
  * 회원 가입시 사용자 정보는 email, 이름 이외에 사번(사원번호)을 전용 고유 식별자로 사용한다.
  * 회원 가입시 입사일을 등록하도록 한다.
  * 사용자는 관리자(manager)와 일반 직원(employee)의 두개 Role로 구분한다.
  * 일반직원은 회원가입을 통해 사용자를 등록할 수 있지만 관리자(manager)는 다른 관리자가 직접 생성해야 한다.
    * 시스템에 처음 회원가입하는 사용자는 자동으로 관리자 역할(manager)이 된다.
  * 가입된 사용자는 사용자 정보를 조회하는 화면에서 비밀번호를 변경할 수 있다.
- 일반 직원은 로그인 후 출근/퇴근을 기록한다.
  * 출근 체크인, 퇴근 체크아웃 시각을 기록한다.
  * 하루 1회 출근, 1회 퇴근을 원칙으로 한다.
- 일반 직원은 연차를 신청할 수 있다.
  * 연차 신청 시 시작일, 종료일, 사유를 입력한다.
  * 연차를 사용할 때 오전, 오후를 나눠서 반차(0.5일)를 사용할 수 있어야 한다.
- 관리자는 직원이 신청한 연차를 승인/반려할 수 있다.
  * 승인/반려 내역과 누가 승인/반려했는지가 기록되어야 한다.
  * 관리자의 연차는 다른 관리자가 승인/반려할 수 있다.
- 관리자와 직원은 월별 근태 현황을 조회할 수 있다.
  * 직원은 본인의 월별 출퇴근 기록과 연차 사용 내역을 조회한다.
  * 관리자는 전체 직원의 월별 출퇴근 기록과 연차 사용 내역을 조회한다.

## 기술 스택
- 백엔드, 프론트엔드, 데이터베이스의 3-tier로 구분하여 개발한다.
  - 데이터베이스
    * PostgreSQL 17 버전의 DB를 사용한다.
  - 백엔드
    * node + Express + javascript 를 이용해 개발한다.
  - 프론트엔드
    * React 최신 버전을 적용한다.
    * 백엔드와의 통신을 위해 Tanstack Query를 사용한다.
    * 전역 상태 관리 라이브러리를 사용한다.
- 인증 기능은 자체적으로 구성한다.
  - JWT 기반의 인증을 사용한다.
  - Access Token과 Refresh Token을 사용한다.
  - 유효 기간은 각각 12시간, 7일로 설정한다.
  - 관리자(manager) / 직원(employee) 역할 기반 접근 제어(RBAC)를 적용한다.
