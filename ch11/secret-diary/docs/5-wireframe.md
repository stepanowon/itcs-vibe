# Wireframe: 나만의 비밀일기 앱

| 항목 | 내용 |
| --- | --- |
| 문서 버전 | v1.0 |
| 작성일 | 2026-07-05 |
| 대상 | 반응형 웹 (Vue) |
| 관련 문서 | [1-prd.md](./1-prd.md), [4-swagger.json](./4-swagger.json) |

> 본 문서는 [PRD 6. 사용자 흐름](./1-prd.md)을 화면 단위로 구체화한 저해상도(Low-fi) 와이어프레임이다.
> 레이아웃은 ASCII 목업으로 표현하며, 각 요소가 호출하는 API(4-swagger.json)를 함께 표기한다.
>
> **설계 원칙: 모바일 퍼스트(Mobile-First).** 기본 목업은 모바일 브라우저(폭 <768px, 세로) 기준으로 그리고,
> 태블릿·데스크톱은 확장 레이아웃으로 기술한다. 주요 화면은 모바일 목업을 우선 제시한다. (NFR-7)

## 1. 화면 목록 (Sitemap)

```
[비로그인]
  ├─ S-01 로그인
  └─ S-02 회원가입

[로그인 후]  (공통: 상단 헤더 + 네비게이션)
  ├─ S-03 일기 목록 (홈, 필터 포함)
  ├─ S-04 일기 작성
  ├─ S-05 일기 상세
  ├─ S-06 일기 수정
  └─ S-07 내 정보 (프로필 + 비밀번호 변경)
```

### 화면 전환도

```
 S-01 로그인 ──(가입하기)──> S-02 회원가입 ──(완료)──> S-01
   │ 로그인 성공
   ▼
 S-03 일기 목록(홈) ◀──────────────────────────┐
   ├─(+ 새 일기)──> S-04 작성 ──(저장)──────────┤
   ├─(카드 클릭)──> S-05 상세 ──(수정)──> S-06 수정 ──(저장)──> S-05
   │                    └─(삭제)──> S-03
   └─(내 정보)──> S-07 프로필/비밀번호
```

## 2. 공통 레이아웃 (로그인 후)

### 모바일 (<768px) — 기본
상단은 얇은 앱바(로고 + 계정 아이콘), 주요 이동은 **하단 탭 바**로 제공한다. (엄지 조작 영역 확보)

```
┌───────────────────────┐
│ 📔 비밀일기        👤  │  ← 상단 앱바 (고정)
├───────────────────────┤
│                       │
│      (화면 본문)       │
│                       │
│                       │
├───────────────────────┤
│   📖 일기    👤 내 정보 │  ← 하단 탭 바 (고정)
└───────────────────────┘
```
- 👤(상단) 탭 → 계정 메뉴(내 정보 / 로그아웃) 시트가 아래에서 슬라이드업.
- 하단 탭: [일기](→S-03) / [내 정보](→S-07). 현재 탭 하이라이트.
- 작성(+)은 목록 화면의 우하단 **플로팅 버튼(FAB)** 으로 제공(아래 S-03 참고).

### 태블릿/데스크톱 (≥768px) — 확장
하단 탭 대신 상단 가로 네비로 전환한다.

```
┌────────────────────────────────────────────────────────┐
│  📔 비밀일기        [일기]  [내 정보]        jimin ▼ ⏻   │
└────────────────────────────────────────────────────────┘
```
- 좌: 로고(→ S-03) / 중: 주요 네비 / 우: 사용자명, 로그아웃(⏻ → `POST /auth/logout`)

## 3. 화면별 와이어프레임

> 인증 화면(S-01/S-02)은 폼 1열 구성이라 모바일·데스크톱 레이아웃이 동일하다.
> 모바일에서는 **풀폭 카드**로, 데스크톱에서는 화면 중앙에 **max-width 400px 카드**로 배치한다.

### S-01. 로그인
> API: `POST /auth/login` · 모바일 기준

```
┌───────────────────────┐
│                       │
│      📔 비밀일기        │
│                       │
│ 이메일 또는 사용자명    │
│ ┌───────────────────┐ │
│ │                   │ │  ← 폭 100%, 높이 44px+
│ └───────────────────┘ │
│ 비밀번호               │
│ ┌───────────────────┐ │
│ │ ●●●●●●●●        👁 │ │  ← 표시 토글
│ └───────────────────┘ │
│ ┌───────────────────┐ │
│ │      로그인        │ │  → 성공 시 토큰 저장 후 S-03
│ └───────────────────┘ │
│ [ ! 이메일 또는       │
│     비밀번호 오류 ]    │  ← 401 시 표시
│                       │
│ 계정이 없으신가요?      │
│           가입하기 →   │  → S-02
└───────────────────────┘
```

### S-02. 회원가입
> API: `POST /auth/signup` · 모바일 기준

```
┌───────────────────────┐
│   ← 회원가입           │
│ 이메일                 │
│ ┌───────────────────┐ │  ← 형식/중복(409) 검증
│ └───────────────────┘ │     inputmode=email
│ 사용자명 (2~50자)      │
│ ┌───────────────────┐ │
│ └───────────────────┘ │
│ 비밀번호 (8자 이상)    │
│ ┌───────────────────┐ │
│ └───────────────────┘ │
│ 비밀번호 확인          │
│ ┌───────────────────┐ │
│ └───────────────────┘ │  ← 불일치 시 인라인 오류
│ ┌───────────────────┐ │
│ │      가입하기      │ │  → 성공 시 S-01
│ └───────────────────┘ │
│ 이미 계정이 있으신가요? │
│            로그인 →    │  → S-01
└───────────────────────┘
```
- 긴 폼은 세로 스크롤. 입력창 포커스 시 모바일 키보드가 가리지 않도록 스크롤 보정.

### S-03. 일기 목록 (홈) + 필터
> API: `GET /diaries?weather=&mood=&tag=&page=&limit=`

**모바일 (기본):** 필터는 상단 **칩(chip) 바** + [필터] 시트로, 목록은 **1열 카드**, 작성은 **FAB(+)**, 페이지네이션은 **무한 스크롤**로 대체.

```
┌───────────────────────┐
│ 📔 비밀일기        👤  │
├───────────────────────┤
│ 내 일기 · 총 42개      │
│ [날씨▾][기분▾][#태그] ⚙ │  ← 가로 스크롤 칩, ⚙=상세필터 시트
├───────────────────────┤
│ ┌───────────────────┐ │
│ │ 비 오는 날의 기록   │ │  → 탭 시 S-05
│ │ 오늘은 하루 종일... │ │
│ │ ☔rainy 😢sad       │ │
│ │ #일상 #비   07-05  │ │
│ └───────────────────┘ │
│ ┌───────────────────┐ │
│ │ 오랜만의 산책       │ │
│ │ 날이 좋아서 공원을..│ │
│ │ ☀sunny 😊happy     │ │
│ │ #운동 #산책 07-03  │ │
│ └───────────────────┘ │
│         ⋮ (스크롤)     │  ← 하단 도달 시 다음 page 자동 로드
│                  ╭───╮ │
│                  │ + │ │  ← FAB → S-04
│                  ╰───╯ │
├───────────────────────┤
│   📖 일기    👤 내 정보 │
└───────────────────────┘
```

  [상세 필터 시트] ⚙ 또는 칩 탭 시 아래에서 슬라이드업:
```
┌───────────────────────┐
│ ══                     │  ← 드래그 핸들
│ 필터                   │
│ 날씨  ◉전체 ○맑음 ○흐림 │
│       ○비 ○눈 ○바람    │
│ 기분  ◉전체 ○행복 ○보통 │
│       ○슬픔 ○화남 ...  │
│ 태그  [ #___________ ] │
│ [초기화]      [적용]   │
└───────────────────────┘
```

**태블릿/데스크톱 (≥768px):** 필터는 상단 인라인 바, 카드 2~3열 그리드.

```
┌────────────────────────────────────────────────────────┐
│  📔 비밀일기      [일기] [내 정보]        jimin ▼ ⏻      │
├────────────────────────────────────────────────────────┤
│  내 일기 (총 42개)                       [ + 새 일기 ]   │  → S-04
│  필터:  날씨[전체 ▼]  기분[전체 ▼]  태그[#___]  [적용]  │
├────────────────────────────────────────────────────────┤
│  ┌────────────────┐  ┌────────────────┐                │
│  │ 비 오는 날의... │  │ 오랜만의 산책   │  ← 2~3열 그리드 │
│  │ ☔rainy 😢sad   │  │ ☀sunny 😊happy │                │
│  └────────────────┘  └────────────────┘                │
├────────────────────────────────────────────────────────┤
│              ◀ 1  [2]  3 ▶   (페이지네이션)              │
└────────────────────────────────────────────────────────┘
```

  [빈 상태] 조건에 맞는 일기가 없을 때 (공통):
  ┌──────────────────────────────┐
  │   아직 일기가 없어요.          │
  │   오늘의 첫 일기를 써보세요!   │
  │            [+ 새 일기]        │
  └──────────────────────────────┘

- 날씨/기분 선택값은 ENUM(4-swagger)과 일치. 태그는 텍스트 입력.
- 필터 변경 시 page=1로 재조회. 데스크톱은 페이지네이션, 모바일은 무한 스크롤로 동일 데이터를 페칭.

### S-04. 일기 작성
> API: `POST /diaries` · 모바일 기준

모바일에서는 상단에 **[취소 / 저장]을 고정 앱바**에 배치(키보드가 올라와도 항상 접근 가능), 날씨·기분은 가로 스크롤 **선택 칩**으로 제공.

```
┌───────────────────────┐
│ ✕        일기 작성  저장│  ← 고정 앱바(저장은 유효 시 활성)
├───────────────────────┤
│ 제목 (필수, ~200자)    │
│ ┌───────────────────┐ │
│ └───────────────────┘ │
│ 본문 (필수)            │
│ ┌───────────────────┐ │
│ │                   │ │  ← 화면 높이에 맞춰 확장
│ │                   │ │
│ └───────────────────┘ │
│ 날씨                   │
│ [맑음][흐림][비][눈]▸  │  ← 가로 스크롤 단일선택 칩
│ 기분                   │
│ [행복][보통][슬픔]▸    │
│ 태그 (최대10, 각20자)  │
│ [ #입력 후 Enter ]     │
│ #일상 ✕  #비 ✕         │
│ [ ! 제목과 본문 필수 ] │  ← 400 시
└───────────────────────┘
```

**태블릿/데스크톱:** 좌우 여백을 둔 중앙 폼, 하단 우측 [취소][저장] 버튼.

```
┌────────────────────────────────────────────────────────┐
│  ← 목록으로                              일기 작성        │
├────────────────────────────────────────────────────────┤
│  제목 [                                              ]  │
│  본문 [                                              ]  │
│  날씨:  (○맑음 ○흐림 ○비 ○눈 ○바람)                      │
│  기분:  (○행복 ○보통 ○슬픔 ○화남 ○설렘 ○피곤)            │
│  태그:  [ #입력 후 Enter ]  #일상 ✕  #비 ✕               │
│                        [ 취소 ]   [ 저장 ]              │  → 성공 시 S-03/S-05
└────────────────────────────────────────────────────────┘
```
- S-06(수정)은 동일 폼에 기존 값 프리필. 모바일 앱바 타이틀만 "일기 수정"으로 바뀐다.

### S-05. 일기 상세
> API: `GET /diaries/{id}` / 삭제 `DELETE /diaries/{id}`

```
┌────────────────────────────────────────────────────────┐
│  ← 목록으로                        [ 수정 ]  [ 삭제 ]     │  수정→S-06
├────────────────────────────────────────────────────────┤
│  비 오는 날의 기록                                       │
│  2026-07-05 21:14  (수정됨: 2026-07-05 21:30)           │
│  ☔ rainy   😢 sad    #일상 #비                          │
│  ──────────────────────────────────────────────────    │
│  오늘은 하루 종일 비가 내렸다.                            │
│  창밖을 보며 커피를 마셨다. ...                          │
│                                                        │
└────────────────────────────────────────────────────────┘

  [삭제 확인 모달]
  ┌────────────────────────────┐
  │  이 일기를 삭제할까요?        │
  │  삭제하면 복구할 수 없어요.   │
  │        [취소]  [삭제]        │  → 삭제 시 S-03
  └────────────────────────────┘
```
- 타인/없는 일기 접근 시 403/404 → "찾을 수 없거나 접근 권한이 없습니다" 안내 화면.

### S-06. 일기 수정
> API: `PUT /diaries/{id}` (기존 값 프리필)

```
┌────────────────────────────────────────────────────────┐
│  ← 상세로                                일기 수정        │
├────────────────────────────────────────────────────────┤
│  (S-04 작성 화면과 동일한 폼, 기존 값이 채워진 상태)      │
│  제목 [비 오는 날의 기록                              ]  │
│  본문 [오늘은 하루 종일 비가 내렸다...                ]  │
│  날씨 (●비)   기분 (●슬픔)   태그 #일상✕ #비✕            │
│                        [ 취소 ]   [ 저장 ]              │  → 저장 성공 시 S-05
└────────────────────────────────────────────────────────┘
```

### S-07. 내 정보 (프로필 + 비밀번호 변경)

┌────────────────────────────────────────────────────────┐

├────────────────────────────────────────────────────────┤

│   └───────────────────────────┘                         │

│                          [ 변경하기 ]                    │

## 4. 상태·예외 UI 규칙 (PRD 8 반영)

| 상황 | UI 처리 |
| --- | --- |
| 로딩 중 | 목록/상세에 스켈레톤 또는 스피너 (TanStack Query `isLoading`) |
| 조회 결과 0건 | 빈 상태(Empty State) 안내 + 작성 유도 |
| 입력 검증 실패(400) | 해당 필드 하단 인라인 오류 메시지 |
| 로그인 실패(401) | "이메일 또는 비밀번호가 올바르지 않습니다" (계정/비번 구분 없음) |
| Access Token 만료 | 백그라운드에서 `POST /auth/refresh` 후 요청 재시도(사용자 무자각) |
| Refresh 만료(401) | 토큰 폐기 후 S-01 로그인 화면으로 이동 |
| 타인/없는 리소스(403/404) | "찾을 수 없거나 접근 권한이 없습니다" 안내 |
| 서버 오류(500) | 전역 토스트 "일시적인 오류가 발생했습니다" |
| 파괴적 작업(삭제) | 확인 모달로 이중 확인 |

## 5. 반응형 규칙 (NFR-7) — 모바일 퍼스트

기본 스타일은 모바일 기준으로 작성하고, 브레이크포인트에서 `min-width`로 확장한다.

### 브레이크포인트별 레이아웃

| 구분 | 폭 | 네비게이션 | 목록 | 필터 | 작성 진입 | 목록 페이징 |
| --- | --- | --- | --- | --- | --- | --- |
| 모바일 | < 768px | 상단 앱바 + **하단 탭 바** | 1열 카드 | 칩 + **바텀시트** | **FAB(+)** | **무한 스크롤** |
| 태블릿 | 768–1023px | 상단 가로 네비 | 2열 그리드 | 상단 인라인(접이식) | 상단 [+ 새 일기] | 페이지네이션 |
| 데스크톱 | ≥ 1024px | 상단 가로 네비 | 2~3열 그리드 | 상단 인라인 | 상단 [+ 새 일기] | 페이지네이션 |

### 모바일 UX 필수 사항
- **터치 타깃 최소 44×44px**, 요소 간 간격 8px 이상.
- **하단 고정 요소(탭 바·FAB·저장 앱바)** 는 iOS/Android의 안전 영역(`env(safe-area-inset-bottom)`)을 존중.
- 소프트 키보드가 입력창을 가리지 않도록 포커스 시 스크롤 보정, 작성 화면의 **저장 버튼은 상단 앱바에 고정**.
- 입력 타입 최적화: 이메일 `inputmode=email`, 적절한 `autocomplete`(현재/새 비밀번호 구분)로 자동완성·키보드 개선.
- 파괴적 작업(삭제)·필터·계정 메뉴는 **바텀시트/모달**로 제공해 엄지 도달성 확보.
- 뷰포트: `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`.

### 공통
- 본문 입력은 화면 높이에 맞춰 확장, 가로 스크롤 발생 금지(콘텐츠 폭 100% 상한).
- 날씨/기분/태그 등 칩·라벨은 폭에 따라 자동 줄바꿈(wrap).
- 이미지·아이콘 외 텍스트는 상대 단위(rem)로 확대/축소 대응.
