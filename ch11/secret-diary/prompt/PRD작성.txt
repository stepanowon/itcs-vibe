# 나만의 비밀일기 앱
## 기능 요구사항
- 사용자는 회원 가입후 로그인해야만 기능을 이용할 수 있다.
  * 회원 가입시 사용자 정보는 email, username 이외의 전용 고유 식별자를 사용해야 한다.
- 사용자는 로그인 후 자신의 일기장에 일기를 쓴다.
  * 일기에는 제목, 본문, 날씨, 현재 나의 기분, 태그 정보를 입력한다.
- 내 일기를 날씨, 기분, 태그로 필터링과 조회를 할 수 있어야 한다.
- 사용자 정보 조회 기능이 있어야 한다.
  * 패스워드 변경 기능이 있어야 함
  * 내가 작성한 일기 갯수 조회할 수 있어야 함

## 기술 스택
- 백엔드, 프론트엔드, 데이터베이스의 3-tier로 구분하여 개발한다.
  - 데이터베이스
    * Supabase의 PostgresqlDB 기능만을 이용한다.
  - 백엔드 
    * node + Express + javascript 를 이용해 개발한다.
    * SOLID 원칙, Clean 아키텍처를 준수한다.
  - 프론트엔드
    * Vue 최신 버전을 적용한다.
    * 백엔드와의 통신을 위해 Tanstack Query를 사용한다.
    * 전역 상태 관리 라이브러리를 사용한다.
- 인증 기능은 자체적으로 구성한다.
  - JWT 기반의 인증을 사용한다.
  - Access Token과 Refresh Token을 사용한다.
  - 유효 기간은 각각 12시간, 7일로 설정한다.
