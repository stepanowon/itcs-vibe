# 업무일지 앱 와이어프레임

`docs/1-prd.md`, `docs/4-swagger.json` 기준으로 작성. 모바일 우선(Mobile First) 반응형 웹 UI를 적용한다.

## 0. 반응형 기준

| 구분 | 너비 | 레이아웃 |
|---|---|---|
| Mobile | ~767px | 1단 세로 스택, 하단 탭 내비게이션 |
| Tablet/Desktop | 768px~ | 상단 헤더 내비게이션, 목록/필터 2단 배치 |

- 모바일: 화면 폭이 좁으므로 필터/작성 폼은 세로로 쌓고, 목록은 카드형으로 표시
- 데스크톱: 좌측에 필터 사이드바, 우측에 목록/상세를 배치하는 2단 레이아웃으로 확장

## 3. 업무일지 목록 화면

### Mobile (~767px) — 카드형 1단 스택, 필터는 접이식(collapsible)

```
┌──────────────────────┐

├──────────────────────┤
│ [ 필터 ▾ ]  [+ 작성]  │  <- 필터 펼침 버튼 + 작성 버튼
├──────────────────────┤
│ (필터 펼침 시)          │
│  완료여부 [ 전체  ▾]   │
│  [ 적용 ]  [ 초기화 ]  │
├──────────────────────┤
│ ┌────────────────┐   │
│ │ 2026-07-15(수)   │   │
│ │ 신규 기능 개발     │   │
│ │ [완료]           │   │
│ └────────────────┘   │
│ ┌────────────────┐   │
│ │ 2026-07-14(화)   │   │
│ │ 버그 수정          │   │
│ │ [진행중]         │   │
│ └────────────────┘   │
│         ...            │
├──────────────────────┤
│ 🏠   📋   👤            │  <- 하단 탭 내비게이션
│ 홈  목록  마이페이지     │
└──────────────────────┘
```

### Desktop (768px~) — 좌측 필터 사이드바 + 우측 목록(표/카드)
```
┌───────────────────────────────────────────────────┐
│ 업무일지 로고        업무일지 목록   내정보   [+ 작성]  │  <- 상단 헤더 내비게이션
├───────────┬───────────────────────────────────────┤
│ 필터        │ 작성일자    제목          완료          │
│ 완료여부    │ 2026-07-15 신규 기능 개발  완료          │
│ [전체 ▾]   │ 2026-07-14 버그 수정      진행중        │
│            │ 2026-07-11 문서 정리      완료          │
│            │ ...                                    │
│ [전체 ▾]   │                                        │
│            │                                        │
│ [적용]     │                                        │
│ [초기화]    │                                        │
└───────────┴───────────────────────────────────────┘
```
- 모바일: 카드 목록 (터치 영역 확보), 필터는 기본 접힘
- 데스크톱: 표 형태 목록, 필터는 항상 노출된 사이드바

## 8. 공통 UI 규칙
- 하단 탭 내비게이션(모바일) ↔ 상단 헤더 내비게이션(데스크톱) 전환은 768px 기준
- 폼 입력 필드는 모바일에서 항상 전체 폭(100%), 데스크톱에서는 2단 컬럼 그리드로 배치
- 버튼/터치 영역은 모바일에서 최소 44px 높이 확보
- 목록 화면은 무한 스크롤 또는 페이지네이션(WorkLogListResponse의 page/limit/total 사용)
