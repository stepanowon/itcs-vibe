# 지뢰 찾기 게임 개발을 위한 PRD

### 기능 요구 사항
- 지뢰찾기 게임은 수준이 상,중,하로 나누어 난이도와 격자의 수를 다르게 지정한다.
- 사용자가 게임을 진행한 내역과 점수를  브라우저 내에 저장하여 최고득점 Top 5를 보여주도록 한다.
- 점수는 시간과 난이도(상중하)를 고려해 계산한다. 계산 로직은 적절하게 적용한다.

### 기술 스택
- 프론트엔드 기반 
- React 19 + Typescript 적용
- 게임의 화면은 깔끔한 화이트톤으로 구성함
